# Confere Chrome — Releases

Repositório público usado somente para distribuição oficial do aplicativo Android Confere Chrome.

- O código-fonte permanece no repositório privado principal.
- O APK oficial é publicado nas Releases.
- `app-version.json` informa ao aplicativo qual é a versão mais recente.
- O aplicativo valida o SHA-256 antes de abrir o instalador do Android.

Não instale APKs do Confere Chrome obtidos de outras fontes.
